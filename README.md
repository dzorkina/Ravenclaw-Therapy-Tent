# Терапевтический шатёр · v.Rave

Отдельная когтевранская версия. Когтеврану от Слизерина.

## Как добавить карточки

1. Положи изображения в `images`.
2. Назови их `01.png`, `02.png`, … `88.png` (номер с нулём).
3. Всё: код менять не нужно. WebP, JPG и JPEG тоже подходят; расширения маленькими буквами. В одном наборе можно смешивать форматы. Пропущенные номера не ломают колоду.

По умолчанию предусмотрено 88 карт. Для другого количества измени только `cardCount` в `config.js`. Если не хочешь переименовывать картинки, перечисли их реальные имена в массиве `files` там же.

Статический сайт не умеет читать содержимое папки на GitHub Pages: поэтому ему нужна либо эта нумерация, либо список имён. Других действий или установки программ не требуется.

## Публикация через GitHub

Загрузи содержимое этой папки в репозиторий. В GitHub Settings → Pages выбери Deploy from a branch, нужную ветку и `/ (root)`.

Все пути относительные: сайт работает и в подпапке репозитория. Сборка, npm и сервер не нужны. Можно открыть `index.html` прямо на компьютере.

## Поведение

Войти → шторы открываются. Колода → случайная карта рубашкой вверх. Нажатие на карту → переворот. «Вытянуть ещё одну» → открытая карта исчезает, новая ложится рубашкой вверх. Карты перемешиваются без повторов до окончания колоды; при новом круге нет немедленного повтора (если карт больше одной).

Все лицевые изображения показываются целиком через object-fit: contain. Их белый фон, если он есть внутри файла, сайт не удаляет. Для прозрачного внешнего фона нужны PNG/WebP с альфа-каналом.

Карточки намеренно не включены: их нужно добавить самостоятельно. Если файлов пока нет, сайт покажет сообщение вместо сломанной картинки. Быстрые повторные нажатия блокируются до окончания анимации. Предусмотрен режим уменьшенного движения, клавиатурная навигация и подписи для экранного диктора.

Шторы, колода, рубашка и орлиная эмблема уже включены. Дымка сделана в CSS, без видео. Подпись и кнопка находятся под картами и на компьютере, и на телефоне.
